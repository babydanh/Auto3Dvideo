# Audit Report — Auto3Dvideo

**Ngày:** 2026-08-23  
**Phạm vi:** Audit sau research MoneyPrinterV2, tập trung vào inventory, contract/implementation drift, secret boundary, executable readiness, external worker gate, native build và regression tests.  
**Trạng thái:** `NEEDS_HUMAN_REVIEW`

## 1. Kết luận

Audit không phát hiện đường gọi provider, publish, scraping, browser automation hoặc general job-linked external worker mới được bật. Native app vẫn giữ worker gate khóa; live external process chỉ tồn tại ở fixture FFmpeg/FFprobe tổng hợp có fixed arguments, output containment và post-probe checks.

Audit phát hiện và đã xử lý ba điểm hardening. Provider command trước đây chỉ kiểm tra sơ bộ credential reference nên một raw value dạng `sk-...` không chứa dấu `=` vẫn có thể được lưu. Tool readiness trước đây có thể báo một file bất kỳ là available dù tên file không khớp tool. ProcessSpec cũng cho phép các environment key nhạy cảm nếu chỉ có prefix `AUTO3DVIDEO_`. Các điểm này đã được khóa bằng validation native, schema pattern, masking ở catalog view và regression tests.

## 5. Residual risks và giới hạn

Build và unit tests không chứng minh chất lượng visual, rights, monetization, platform approval hoặc production readiness. Chưa có provider API call thật, voice/likeness review thật, ComfyUI graph, Blender render job, general user-media processing, durable external-result persistence, restart reconciliation hoặc full manual UI click-through. FFmpeg fixture chỉ là synthetic one-second output, không phải video người dùng.

Credential hardening hiện bảo vệ persisted references và child-process boundary. `os:handle` mới là handle hợp lệ về mặt contract; app chưa tích hợp Windows Credential Manager/OS keychain để resolve nó. Environment references chỉ là development mechanism và không được xem là secret store trong packaged app.

## 6. Policy, rights và cost

Không đọc hoặc lưu `.env`, API key thật, private key, credential, dữ liệu cá nhân, video người dùng hoặc Zalo data. Không gọi cloud provider, không chạy publish, scraping, outreach, affiliate, browser profile automation, watermark removal, reposting hoặc account/region bypass. FFmpeg/FFprobe chỉ được dùng cho synthetic fixture với fixed app-owned arguments sau khi user đã cấp phép cài đặt tool.

Chi phí phát sinh của audit là **0 USD**. Rights/provenance, voice/likeness consent, music license, AI disclosure, privacy, budget và platform checks vẫn là gate riêng; không có claim output đã publishable/monetizable.

## 8. Follow-up local software integration — 2026-08-23

Phần audit ban đầu ở trên ghi nhận trạng thái trước khi nối external fixture. Follow-up này cập nhật bằng chứng: `run_ffmpeg_fixture_attempt` hiện tạo `ffmpeg_fixture` job, claim `external_process` attempt, chạy fixed FFmpeg/FFprobe arguments qua direct no-shell supervisor, persist terminal attempt/output evidence, log byte counts và audit events. Timeout hoặc cancellation có side effect chưa xác định sẽ chuyển attempt và parent job sang `reconciliation_required`; startup sẽ reconcile các external attempt còn `running` hoặc `cancel_requested` sau restart. Race giữa cancel request và process completion đã được xử lý để không bỏ lại attempt ở state trung gian.

Settings hiện có Probe cho FFmpeg, FFprobe, Python và Blender; Probe chỉ chạy fixed version command qua supervisor và tách khỏi readiness metadata. ComfyUI có loopback-only `GET /system_stats` health check, không submit workflow/prompt, không cài custom node và không gọi endpoint remote. Blender có deterministic synthetic-cube fixture dùng script app-owned và output `.blend` trong workspace; command chỉ chạy khi `blender.exe` được cấu hình đúng expected filename. Không cài Blender trong slice này.

Finding OPS-02 về external fixture persistence và restart reconciliation đã được xử lý cho đường `ffmpeg_fixture` cố định; general typed media-plan execution và user-media worker vẫn chưa được mở. Finding OPS-01 vẫn mở: cần human click-through Settings → Probe/ComfyUI/fixtures → Jobs → evidence trên Windows. Finding OPS-03 vẫn mở một phần: `os:handle` mới được validate/mask về contract, Windows Credential Manager chưa resolve thật; ComfyUI graph submission, Blender scene/render jobs, cloud/provider calls và publishing vẫn chưa có.

Follow-up evidence: default Rust library suite có 25 test pass và 1 live fixture test ignored by default; live FFmpeg/FFprobe test đã pass khi truyền explicit verified D-drive paths. Loopback health, output persistence, unknown-side-effect reconciliation, startup reconciliation, cancellation race, migration idempotency và process safety đều có regression coverage. Frontend `pnpm build` pass. Các metrics static current vẫn là 184 manifest/physical files, 33 JSON, 14 YAML và 25 relative Markdown links nếu chưa có thay đổi inventory mới.

Residual risks không đổi: đây chưa phải production-ready worker; richer codec/dimension/frame-rate validation, typed media-plan compiler cho input user-owned, retry policy cho reconciliation, OS credential resolution, real ComfyUI queue/status/output ingestion, Blender scene/render contract, editor handoff, rights verification, visual quality, accessibility, platform approval và final human review vẫn cần triển khai/kiểm tra riêng. Cost impact vẫn là 0 USD và không có cloud/provider/publish action nào được thực hiện.

Review sau integration xác nhận điểm yếu visual montage đã được xử lý ở tầng planning trước generation, chưa phải bằng cách đổi model ngẫu nhiên. Review surface hiển thị beat timing, narration, claim, visual intent, entity anchors, expected visual evidence, expected output path và prompt mở rộng; không gọi image/video provider, ComfyUI graph hay cloud endpoint.

Residual risks: semantic score/CLIP judge chưa tích hợp, provider/image generation chưa bật, candidate output chưa ingest, user-owned media chưa chạy qua general media-plan executor, và click-through thủ công toàn bộ Review → generation gate vẫn cần người dùng kiểm tra.
